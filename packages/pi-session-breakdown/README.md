# Session breakdown extension

Use `/session-breakdown` to inspect read-only Pi usage analytics over the last 7, 30, or 90 days. It renders a calendar heatmap and top tables by model, project directory, weekday, or time of day, with message, token, and cost totals from local session logs.

Adapted unchanged apart from provenance notice from `mitsuhiko/agent-stuff` commit `3c891a9640f80c271ccc666ab7a39f9811bc3fb6` under Apache-2.0. See `extensions/session-breakdown/LICENSE.agent-stuff`.
